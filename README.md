Vibe Video｜视频制作流程与技能手册

一个帮助你从灵感走向成片的中文导航网站。

网站将视频制作拆解为清晰的流程，整理每一步可使用的 Agent Skills、开源工具和制作方法。你可以先了解全流程，也可以直接查找配音、白模、字幕等具体任务的做法。

> 本站提供制作指导与工具导航。实际生成、配音、剪辑和渲染，需要在对应的编码助手、软件或服务中完成。

## 适合谁使用

- **刚开始做视频的人**：了解从脚本到成片需要哪些环节。
- **使用 AI 编码助手的创作者**：找到可安装的 skill，并复制任务描述开始制作。
- **制作 AI 短片的人**：查找角色一致性、关键帧和白模控制等工作流。
- **正在解决具体问题的人**：直接寻找配音、音乐、音效、转写、字幕或导出工具。

## 网站有哪些功能

### 1. 首页流程动效

首页用约 18 秒的循环动画演示六阶段制作流程：

**创意 → 分镜 → 视觉 → 动效 → 声音 → 导出**

点击动效中的阶段按钮，可以跳到对应的演示画面；点击播放或暂停按钮，可以控制演示。系统启用减少动态效果时，动效默认暂停，可手动播放。

### 2. 六阶段流程地图

点击流程节点，查看该阶段的目标、产出及技能指南。

| 阶段 | 主要解决的问题 | 典型产出 |
| --- | --- | --- |
| 创意与策划 | 给谁看、说什么、采用哪种形式 | 创作 Brief、时长与画幅、场景清单 |
| 脚本与分镜 | 每一镜拍什么、持续多久、如何衔接 | 分镜表、台词、时间线 |
| 视觉与素材 | 画面采用什么风格、需要哪些素材 | 关键帧、视觉规范、角色参考 |
| 动效与合成 | 如何实现运动、转场和镜头组合 | 动效组件、生成镜头、可预览工程 |
| 声音与字幕 | 如何配音、配乐、加音效并对齐字幕 | 旁白、音乐、音效、字幕时间轴 |
| 检查与导出 | 如何检查成片并准备发布 | MP4、字幕、封面、归档工程 |

每个阶段下方还会列出相关资源。点击资源，可跳转到制作手册中的对应分类。

### 3. 技能指南

选中流程节点后，可在指南中切换：

- **使用指南**：查看该阶段的操作步骤。
- **示例提示词**：复制任务描述，修改后交给编码助手。
- **最新技能原文**：联网读取 GitHub 上的技能文件，了解上游当前说明。

支持复制安装命令，并通过“查看源文件”打开原始文档。

### 4. 制作手册

当前收录 **17 项指南**，覆盖策划、分镜、视觉、镜头、动效、配音、声音、音乐、音效、字幕、多语言、后期和交付。

每项指南包含：

1. 适用场景与使用前提。
2. 开始前需要准备的材料。
3. 按顺序执行的制作步骤。
4. 应交付的文件或成果。
5. 可复制的任务描述。
6. 验收标准。
7. 安装或获取方式，以及原始文档链接。

你可以使用分类按钮筛选，也可以通过搜索框查找“配音”“白模”“中文”“字幕”等关键词。分类与搜索会同时生效；想重新搜索全部内容时，先选择“全部”。点击卡片即可展开或收起详情。

### 5. 声音制作专项

声音部分按任务细分，方便根据实际需求选择：

| 需求 | 网站中对应的指南 |
| --- | --- |
| 生成旁白或角色台词 | ElevenLabs `text-to-speech` |
| 快速制作中文旁白草稿 | `edge-tts` 开源工具 |
| 清理录音中的背景噪声 | `voice-isolator` |
| 生成背景音乐 | `music` |
| 生成转场、环境或动作音效 | `sound-effects` |
| 语音转写与时间信息 | `speech-to-text` |
| 自行运行模型进行本地转写 | `faster-whisper` 开源工具 |
| 制作其他语言的配音版本 | `dubbing` |

建议先用两句台词或一小段音频试听，确认音色、发音和效果，再处理完整内容。字幕应以最终音频的真实时间信息为依据。

### 6. 制作方法板块

展示四种可进一步学习的路线：

- **白模 → 风格参考 → 视频**：先用简化几何预演空间、走位和相机运动，再结合参考图生成正式画面。
- **先定角色，再分镜生成**：先建立角色参考包，再逐镜制作并检查一致性。
- **先锁关键帧，再生成运动**：确认首帧等关键画面后，为镜头添加受控动作。
- **代码动效 × AI 镜头**：AI 生成环境与镜头素材，代码负责准确的文字、图表、字幕和时间编排。

展开方法卡片，可以查看适用场景、步骤、注意点、可复制任务描述与来源。这些内容是方法精选，不代表全网热度排名。

### 7. GitHub 动态

展示相关仓库的 Stars、Forks、开放议题计数及最近提交。当前跟踪 Remotion、Anthropic Skills、ElevenLabs Skills、fal 社区 Skills、白模工作台、Edge TTS 和 faster-whisper 七个来源。

- 点击“同步 GitHub”可手动刷新。

## 第一次使用：建议这样开始

1. **明确作品目标**：写下主题、受众、时长、画幅和参考风格。
2. **选择制作路线**：参考“新手产品片”“AI 叙事短片”或“真人口播”路线卡。
3. **定位当前阶段**：在流程地图中选择需要完成的环节。
4. **展开详细指南**：确认输入材料、工具条件、安装方式与预期产出。
5. **在外部工具中执行**：将示例里的占位内容换成自己的需求，交给支持该 skill 的编码助手或对应软件。
6. **先做短样**：用一个镜头或两句配音验证效果，再扩展到整片。
7. **按验收标准复核**：完成当前步骤后，将产出交给下一阶段。

例如，制作一支 30 秒产品介绍视频，可以采用：

```text
需求与脚本
  → 视觉关键帧（frontend-design）
  → 动效与合成（Remotion）
  → 旁白（text-to-speech 或 edge-tts）
  → 字幕与混音
  → 成片检查与导出
```

这是一条参考路线，可以按项目调整。旁白驱动的视频应尽早确认真实音频时长，再细化时间线。

## Skill、工具和服务有什么区别

- **Skill**：给兼容 AI 助手使用的任务说明与知识包。安装后仍可能需要额外软件或 API 服务。
- **开源工具**：例如 Edge TTS、faster-whisper，需要在自己的环境中安装运行。
- **生成服务**：执行配音、音乐或视频生成的模型服务，可能需要账户、API Key 和可用额度。
- **本站指南**：帮助选择和使用这些资源，本身不会安装 skill，也不会调用模型生成作品。

官网或社区发布的来源会在卡片中标注。示例提示词由本站编写，使用前应替换项目参数、素材路径和原稿内容。

## 使用时需要了解

- 阅读指南无需 API Key。GitHub 同步、技能原文和网络字体需要网络连接。
- 安装命令应在自己的终端或编码助手环境中执行。
- 服务密钥应配置在实际制作环境中，不要写入公开仓库；本站不提供密钥输入功能。
- 第三方模型的支持能力、费用、授权范围和安装方式，以来源项目的最新说明为准。
- 白模或参考图可以帮助控制生成结果，但仍需检查变形、出画、角色变化等问题。
- 本仓库包含网站代码与指南，不包含第三方模型、音色、生成素材或所引用 skills 的完整安装包。

## 项目说明

网站采用 HTML、CSS 和 JavaScript 实现，可作为静态网站部署，无需 npm 构建。

内容维护主要位于：

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构与板块介绍 |
| `app.js` | 六阶段指南与 GitHub 数据同步 |
| `library.js` | 制作手册、参考路线与方法教程 |
| `motion.js` | 首页流程动效 |
| `style.css`、`refined.css`、`library.css`、`motion.css` | 页面样式 |

指南会随工具和工作流发展继续整理。遇到过时命令、失效链接或有值得补充的方法，可以通过仓库 Issues 或 Pull Request 提出建议。
